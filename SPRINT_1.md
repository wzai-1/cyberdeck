# Sprint #1 — Foundation

## Goal
A working combat loop in browser. Player can draw cards, play them, deal damage, block, end turn, enemy attacks back. Win or lose screen.

## Tasks
- [x] BACKLOG.md created
- [ ] Project scaffold (Vite + TypeScript + PixiJS v8 + Vitest)
- [ ] Core game state (pure functions, serializable)
- [ ] Combat engine (HP, mana, turn system)
- [ ] Card system (draw/play/discard/exhaust)
- [ ] 5 starter cards (Strike x3 = 6dmg, Block x2 = 5shield)
- [ ] Enemy AI (intent system: attack/defend)
- [ ] Combat UI (cyberpunk neon style)
- [ ] Unit tests ≥80% coverage on game logic
- [ ] Push to GitHub main

## Definition of Done
- `npm test` passes
- `npm run dev` launches in browser
- Can complete a full combat: draw cards → play → end turn → enemy attacks → win or lose
